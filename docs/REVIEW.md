# Vantage 本地演示修复与清理验收

验收日期：2026-10-05。目标是招聘方能够在本地安装、运行和演示项目。
本轮保留 mock、Qwen、OpenAI；未恢复 Gemini，未引入定时调度、鉴权或界面重设计。

## 结论与验证范围

核心流程和本轮确认的缺陷已修复。离线测试、真实采集配合 mock 推理的
quick 流程均通过。真实 Qwen/OpenAI 推理尚未验收，因此不能把当前结果表述为
“真实模型分析质量已验证”或“已达到公网生产部署要求”。

| 前端 `npm run test` | Vitest 11 项通过；覆盖请求失败、事件去重、最多 3 次重连、终态关闭、报告缓存和章节旧稿清理 |

真实采集使用现有搜索配置和真实公共来源，模型提供方明确为 **mock**：
研究阶段约 77.2 秒，保存 69 条证据、7 个章节、46 条追踪记录、2 个图表，

最终保留 7 个未解决问题；模拟报告明确显示 `[MOCK]`，没有将检查结果包装为完美报告。
这些数量是本次单次采集结果，会随网络和来源变化。

测试使用临时数据库和采集夹具；真实采集也使用独立数据库。

浏览器结果不能替代真实模型测试或真实网络在浏览器全链路中的验收。

## 已修复的问题

- **比较主体丢失**：任务持久化识别范围和澄清问题。选择 Obsidian 后仍保留 Notion；
  用户提交不能覆盖内部模式、范围及关注项元数据。
- **SSE 重复研究**：后台任务独立于连接，任务通过 SQLite 原子领取，多个订阅共享一次执行。
  运行中按序号回放；`after` 和 `Last-Event-ID` 支持恢复，非法游标拒绝。
- **刷新和终态恢复**：新增任务详情 API，恢复问题、问卷、答案、状态和报告链接。
  完成任务返回既有报告；失败、中断任务不会自动重跑；已删除报告的任务流返回 410。
- **后台中断**：启动时标记上次未完成任务中断，关闭时持久化中断状态。
  运行缓冲在内存，终态序号、错误与报告关联存 SQLite。
- **错误被当成成功**：空白查询、非法模式、未知任务/报告返回明确错误；
  澄清提交、反馈、关注项删除失败不返回伪成功，界面按服务端结果处理。
  SSE 业务终态主动关闭连接，客户端每次订阅最多重连 3 次，保留 React StrictMode。
- **报告关联和缓存丢失**：反馈和重写保留任务、收藏、报告名称；详情和列表缓存同步更新
  mock 标记、摘要及统计。章节重写成功后清理该章节旧编辑稿，避免遮住新内容，批注保留。
- **致命模型失败被降级吞掉**：缺失配置、401/403、429 重试耗尽和本地日配额耗尽
  向上抛出并终止任务。全部正文生成失败且验证后仍失败时不保存成功报告。
- **关注项入口缺失**：补充 `Research now`，创建关联 `subscription_id` 的 quick 任务，
  成功后更新运行次数和最新报告；不增加定时调度。
- **抓取内网风险**：限制 HTTP/HTTPS 公共地址，拒绝用户信息 URL、本机、私网、链路本地、
  保留/组播和混合 DNS 地址。每跳检查重定向，连接固定已校验 IP，保留原 Host/TLS SNI，
  关闭环境代理继承。解压后的正文最多 2 MiB，被拒地址不进入证据集合。
  增加压缩正文只解码一次的测试。
- **复现文档错误**：修正 robots.txt 已实施的不实声明，更新 Node 引擎范围为
  `^20.19.0 || >=22.12.0`，安装使用 `uv sync --locked` / `npm ci`。

## 已知风险与未验证项目

**真实模型**：没有可用 Qwen/OpenAI 配置来进行真实推理验收。现有测试验证了 HTTP
适配器契约、参数和错误行为，不能代替实际账号、区域、额度、模型输出质量和长时稳定性测试。

**部署边界**：本地可信单用户、单后台进程。没有鉴权、用户隔离或公共 API 限流，
CORS 不是权限控制，不能直接公开部署。多 worker、分布式队列、跨后台重启续跑不在本轮范围。
运行中全部事件仅保存在内存，长期任务缓冲规模未做压力基准。

**采集与质量**：自动 robots.txt 遵守尚未实现。来源可失效、限流或变化；抓取失败时可能
使用公开来源的摘要，报告中的来源链接、降级和质量问题仍需人工判断。
“独立域名”是规则判定而非事实独立性的保证；mock 没有真实模型的事实审查或商业推断能力。

**开发依赖**：审计时高风险条目为 `brace-expansion`、`braces`、`chokidar`、
`fast-glob`、`micromatch`、`nanoid`、`tailwindcss`。后五项中的部分是沿依赖链传播的告警。
截至本次检查，[braces 公告](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)
没有已发布的补丁版本；npm 提议通过迁移 Tailwind 4 绕开旧依赖，本轮按约定不迁移。
`brace-expansion` 和 `nanoid` 的审计标明存在可用修复，作为后续专门依赖维护处理。
本轮未做 Python 依赖的全面漏洞审计、历史 Git 秘钥扫描或公开服务渗透测试，
“生产 npm 审计为 0”不能解释成项目没有任何漏洞。

**求职表述**：可展示可追溯研究流程、规则质量门、SSE 生命周期、缓存一致性和防内网抓取。
52 位专家是角色配置与任务分工，不是 52 个独立部署服务；界面的效率倍数以预设人工
基线估算，不是客户实验测得的收益。真实模型验收完成前，应明确区分模拟演示和真实分析。

后续方向仅记录：真实模型验收、自动 robots 策略、开发依赖升级、鉴权和请求限流、
持久任务队列与事件缓冲上限，以及更严格的事实支持评估。本轮未实施这些扩展。
